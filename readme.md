# 猜数字小游戏（Guess the Number）

一个用 Python 编写的命令行小游戏：电脑随机想出一个 **1-100** 之间的整数，玩家不断输入猜测，程序提示「大了」或「小了」，直到猜中为止，并统计一共猜了几次。

整个游戏**单文件完成**，只使用 Python 标准库（`random`），无需安装任何第三方依赖。

---

## 功能特性

- 随机生成 1-100 的整数答案，每局都不一样
- 实时提示「大了」/「小了」，逐步缩小范围
- 猜中后显示答案与**本局猜测次数**
- 输入校验：空输入、非数字、超出范围都会友好提示并要求重新输入，不会崩溃
- 支持连续多局，退出时显示**本次最佳成绩**
- 支持 Ctrl+C / Ctrl+D 优雅退出，不打印异常堆栈

## 游戏规则

1. 程序在 1-100 之间随机生成一个整数作为答案。
2. 输入你猜测的整数并按回车。
3. 程序给出反馈：
   - **大了** —— 你猜的数字比答案大
   - **小了** —— 你猜的数字比答案小
   - **猜中** —— 显示答案和本局总次数
4. 一局结束后可以选择 `y` 再来一局，输入其他内容则退出并显示最佳成绩。

**小提示**：每次都在当前可能范围的中间取值（二分法），100 以内的数字最多 **7 次**就能保证猜中。

## 代码结构

| 位置 | 名称 | 职责 |
| --- | --- | --- |
| `LOW` / `HIGH` | 范围常量 | 统一控制数字范围，改动只需改这两处 |
| `read_guess(attempt)` | 输入校验 | 循环读取，直到取得范围内的合法整数才返回 |
| `play_once()` | 单局流程 | 生成答案、比较大小、打印提示，返回本局次数 |
| `main()` | 多局调度 | 反复开局、记录最佳成绩、处理是否再来一局 |
| `if __name__ == "__main__"` | 程序入口 | 直接运行时才启动游戏，被导入时不自动执行 |

## 常见问题

**Q：输入小数可以吗？**
A：不可以，会提示「不是有效的整数」，请输入整数（如 `50`）。

**Q：怎么修改数字范围？**
A：打开 `guess_number.py`，修改文件顶部的 `LOW` 和 `HIGH` 两个常量即可，提示语和校验会同步变化。

**Q：为什么提示「第 1 次猜测」重复出现？**
A：说明上一次输入不合法，程序在要求你重新输入，非法输入不计入次数。

**Q：运行时出现 `ModuleNotFoundError`？**
A：说明用错了 Python 解释器；确认 `python --version` 输出 3.6 以上，或改用 `python3 guess_number.py`。
